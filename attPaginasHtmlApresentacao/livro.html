GitHub na Prática

Um livro digital para quem quer sair do zero e aprender a guardar, versionar e publicar projetos no GitHub, sem decorar comandos e sem complicação.

Cada capítulo termina com um exercício prático, construindo aos poucos um perfil profissional na plataforma que as empresas de tecnologia mais utilizam.

Quero aprender GitHub

O que você vai aprender

  1. O que são Git e GitHub e por que todo desenvolvedor usa.
  2. Criando sua conta e o primeiro repositório.
  3. Git no terminal: init, add, commit e push.
  4. Branches e merge: trabalhando sem quebrar o que já funciona.
  5. Pull requests e revisão de código.
  6. Issues e Projects: organizando tarefas.
  7. GitHub Pages: publicando seu site de graça.
  8. GitHub Actions: automatizando o deploy.
  9. Perfil profissional: README de perfil e portfólio.
